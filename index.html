🔒 Data Privacy & Third-Party Network Disclosures

GoldenHour processes user inputs client-side and stores records locally. The following external network transmissions occur strictly for map rendering and speech:

  • OpenStreetMap Tile Servers: Standard HTTP tile requests (tile.openstreetmap.org) receive client IP and viewport coordinates to render map graphics. Zero tracking tokens are sent.
  • Nominatim Reverse Geocoding & Search: On user request (GPS detect, map click, or area search), coordinates/query are transmitted to OpenStreetMap's public geocoding API to resolve street addresses.
  • Browser Speech Synthesis: Audio guidance uses the native browser Web Speech API (window.speechSynthesis). Depending on the host OS and browser vendor, synthetic voice processing may occur locally on-device or via the browser's cloud speech engine.

⚕️ Clinical Sourcing & Non-Diagnostic Disclaimer

All first-aid instructions are curated from publicly available Basic Life Support (BLS) protocols published by the Indian Resuscitation Council (IRC) and the European Resuscitation Council (ERC). GoldenHour is an educational bystander coordination prototype and is not a certified medical device. It does not perform clinical diagnosis, triage scoring, or replace licensed paramedics. Always prioritize calling 112 in any life-threatening emergency.
